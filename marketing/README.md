# Café Promotion Workspace

A lightweight marketing workspace for cafés, restaurants, and food brands. The aim is practical growth through accurate listings, useful websites, appealing content, ethical review practices, and a better customer experience.

## Start here

1. Read [`AGENTS.md`](AGENTS.md), the marketing chief-of-staff playbook.
2. Review [`clients/yummy-ranchi.md`](clients/yummy-ranchi.md), the first business profile from the shared Maps link.
3. Pick the relevant role brief in [`agents/`](agents/).
4. Use the audit or campaign template in [`templates/`](templates/) and save completed work in `campaigns/YYYY-MM-business-name/`.
5. The reusable [`cafe-local-marketing` skill](skills/cafe-local-marketing/SKILL.md) works in this repository; the same skill is also installed in the Manus skill library.

## Structure

```text
cafe-promotion/
├── AGENTS.md
├── README.md
├── agents/                     # Focused marketing role briefs
├── clients/                    # Client briefs and reusable intake
├── campaigns/                  # Approved, dated campaign work
├── templates/                  # Audit and campaign templates
└── skills/             # Repo-portable agent skill
```

`campaigns/` is intentionally empty until a real campaign is approved. Do not store passwords or private customer information here.
