# Campaigns

Save each approved campaign in `YYYY-MM-business-name/` (for example, `2026-11-yummy-ranchi/`). Include only what is useful: `brief.md`, approved copy, asset inventory, publication links, and a short results note. Drafts should be marked `DRAFT`; owner-approved materials should record approval date and approver. Never publish directly from a draft or store credentials/customer personal data here.
