# Marketing roles

These are role briefs for Manus or another AI agent to follow. They are not separate running bots or external integrations. The root [`AGENTS.md`](../AGENTS.md) is the chief of staff: it assigns only the roles a task needs, coordinates independent work, and synthesizes a single owner-ready recommendation.

Use one specialist for a narrow request. For a full café promotion review, delegate in parallel to local visibility/reputation, website/conversion, brand/content, and customer experience/operations. Add growth/measurement to set outcomes and assess feasibility. Every specialist should distinguish evidence from assumptions, cite source links when relying on public facts, and request owner confirmation for unknown business details.
